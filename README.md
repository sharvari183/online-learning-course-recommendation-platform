
# 📘 Online Learning & Course Recommendation Platform

## 🚀 Project Overview

The **Online Learning & Course Recommendation Platform** is a full-stack EdTech system that allows users to browse courses, enroll, track progress, and receive AI-powered personalized course recommendations.

The recommendation engine uses **content-based filtering (TF-IDF + cosine similarity)** and graph-based visualization to simulate real-world platforms like Coursera and Udemy.

---

## 🎯 Problem Statement

Traditional learning platforms have:
- Poor course discovery
- No personalization
- Low engagement
- Random course suggestions

This project solves it using:
- AI-based recommendations
- Skill-based filtering
- Similar course suggestions
- Graph-based learning insights

---

## ✨ Features

### 👨‍🎓 User Features
- User registration & login
- Browse courses
- Enroll in courses
- Track progress
- View recommendations

### 🤖 Recommendation System
- TF-IDF based content similarity
- Cosine similarity matching
- Similar course suggestions
- Skill/tag-based filtering

### 📊 Visualizations
- Course similarity heatmap
- Course network graph
- Recommendation score bar chart

---

## 🧠 Recommendation Logic

- Convert course tags into vectors using TF-IDF
- Compute cosine similarity between courses
- Recommend top similar courses
- Visualize relationships using graphs
